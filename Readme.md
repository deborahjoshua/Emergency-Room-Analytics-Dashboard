# ER Operations & Patient Experience Dashboard

## Project Overview
Interactive Power BI dashboard analyzing emergency room operations and patient experience metrics.

## Key Metrics
- Total Visits
- Year-over-Year Growth
- Average Wait Time
- Satisfaction Score
- Referral Distribution
- Demographic Breakdown

## Tools Used
- Power BI
- DAX (Measures & Time Comparison)
- Power Query
- Data Modeling
